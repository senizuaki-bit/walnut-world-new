# Bug 军团后端复查（2026-09-10）

范围：`walnut-world-all` 本地 `all` 工作区。本轮只修改后端，不改正式前端。

## 发现并修复

| 问题 | 修复前的复现证据 | 修复后 |
| --- | --- | --- |
| 请求取消导致重复工作 | 判题开始后取消等待，再用同一 answer_id 提交，判题调用次数为 2 | 已开始的任务与 HTTP 等待解耦；保留任务直到保存结果。出题、判题、总结均覆盖，重试只生成/判题一次 |
| 缓存语音被其他生成阻塞 | 另一条 TTS 在等待服务时，已缓存音频请求也无法返回 | 缓存命中直接返回；未命中仍保留合成锁和二次缓存检查 |
| 错误参数被误报为服务故障 | 真实接口 prepare 收到对象、数组或 false 类型的 run_id，返回 503 / retryable=true | 先校验 run_id，统一返回 400 / PRACTICE_RUN_INVALID / retryable=false |

取消恢复测试在应用服务边界模拟请求取消，并不声称所有浏览器断网行为都会取消服务器协程。网关重启仍会使 Demo 练习状态失效，规则不变。
