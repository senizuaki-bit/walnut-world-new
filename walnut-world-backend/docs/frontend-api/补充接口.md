# 教师与可选接口

更新：2026-09-09。返回 [联调主文档](README.md)。这些接口与游戏主链路分开使用，配置启用不等于已完成所有前端联调。

## 1. 可用性与入口

| 功能 | 实际入口 | 条件 |
| --- | --- | --- |
| 世界动画事件 | `GET /v1/worlds/{world_id}/presentation-events` | `WALNUT_ENABLE_WORLD_PRESENTATION=true` |
| 代码建议决定 | `POST .../patches/{patch_id}/decision` | `WALNUT_ENABLE_SKILL_PATCH=true`，同时启用 WORLD_PRESENTATION |
| 客户端事件上报 | `POST /v1/client-events:batch` | `WALNUT_ENABLE_CLIENT_EVENT_BATCH=true` |
| 世界事件 WebSocket | `WS /v1/realtime` | `WALNUT_ENABLE_REALTIME_WSS=true` |
| 问叮当语音 | `WS /product-experience/v1/sessions/{session_id}/dingdang-voice` | 路由始终存在；后端 `YAYA_VOICE_MODE=doubao` 且配置有效 |
| 教师学习／班级／证据读取 | 下述三个 Feishu REST 接口 | 路由已挂载；要求教师等有相应权限的身份 |
| 教师 MCP | `POST /integrations/feishu/v1/mcp` | 路由已挂载；教师权限、JSON-RPC 协议 |

`GET /product-experience/v1/capabilities` 返回动画／代码建议能力。世界 WSS 与事件上报能力由兼容的 `GET /v1/bootstrap` 返回 `capabilities.world_event_stream`、`capabilities.client_event_batch`。语音启用状态不在前一个 capability 对象里，连接时可能返回 `VOICE_DISABLED`。

## 2. 教师查询学习记录

这些接口采用普通 HTTP 请求头。两个 POST 查询也要求 Idempotency-Key，使用本次查询的稳定业务键。body 中的 context 需要匹配当前教师身份与所查询的关卡内容；不能靠填写 `actor_type=teacher` 给学生 token 增加权限。

| 接口 | 请求与响应 |
| --- | --- |
| [POST /integrations/feishu/v1/learner-queries](HTTP接口参考.md#querylearnerprojectionfromfeishu) | 请求含 context、learner_ref、purpose、requested_fields、consent_basis 等；返回 mastery_summary、recent_evidence、support_needs、data_freshness 等 |
| [POST /integrations/feishu/v1/class-insights](HTTP接口参考.md#queryclassinsightsfromfeishu) | 请求含 context、class_ref、purpose、time_range、dimensions、privacy；返回 cohort_size、privacy、insights |
| [GET /integrations/feishu/v1/evidence/{evidence_id}?purpose=...](HTTP接口参考.md#getredactedevidenceforfeishu) | 必须提供 purpose，读取脱敏证据摘要和允许展示的链接 |

完整示例：[学生查询](examples/feishu-learner-query.json)、[学生响应](examples/feishu-learner-query-result.json)、[班级查询](examples/feishu-class-insights-query.json)、[班级响应](examples/feishu-class-insights-result.json)、[证据响应](examples/feishu-evidence-view.json)。具体用途枚举、时间范围和字段权限看对应字段参考。

`learner_ref`、`class_ref` 是教师查询使用的脱敏引用，不是游戏里的 actor_id/session_id。由后端已有数据或教师集成配置提供，不在前端硬编码哈希算法。结果可能明确标注样本不足、数据尚未更新或字段隐藏，前端保留这些含义，不当作零分或已掌握。

## MCP

地址：`POST /integrations/feishu/v1/mcp`。这是教师工具调用入口，不是普通游戏聊天接口，也不提供 SSE 音频流。

必须携带教师 `Authorization: Bearer <token>` 和 `Content-Type: application/json`。本接口允许省略公共 attempt headers，由后端生成；省略 X-Schema-Version 时按 1.0.0。initialize 之后携带协商得到的 `MCP-Protocol-Version`，支持 `2025-06-18`、`2025-03-26`。当前拒绝带 Origin 的调用，适合 MCP 客户端／服务端集成，不给网页直接当跨域 AJAX 使用。

初始化请求：

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-06-18",
    "capabilities": {},
    "clientInfo": {"name": "walnut-teacher-client", "version": "1.0.0"}
  }
}
```

响应为 `{"jsonrpc":"2.0","id":1,"result":{...}}`，result 包含 protocolVersion、capabilities、serverInfo 和 instructions。读取返回的协议版本供后续请求头使用。

随后发送无 id 的通知 `{"jsonrpc":"2.0","method":"notifications/initialized"}`，返回 HTTP 202、无响应体。接口不要求维护 MCP session token。

列工具：

```json
{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}
```

| 工具名 | 用途 |
| --- | --- |
| `query_learner_progress` | 按 learner_ref 查询学习进展，可附 content_ref/time_range |
| `query_class_common_issues` | 班级共性问题，可附 class_ref/content_ref/time_range |
| `get_evidence_summary_and_links` | 按 evidence_id 查询证据摘要和链接 |

工具参数的完整 JSON Schema 已放在 [feishuTeacherMcp](HTTP接口参考.md#feishuteachermcp)。省略可选范围时使用后端声明的默认范围与消歧规则，不等于读取任意关卡。

调用示例：

```json
{
  "jsonrpc":"2.0",
  "id":3,
  "method":"tools/call",
  "params": {
    "name":"query_learner_progress",
    "arguments":{"learner_ref":"lrn_00000001"}
  }
}
```

解析 JSON-RPC 顶层 error，再检查工具 result 的 `isError`、`content` 等字段；不能只凭 HTTP 200 判断业务查询成功。错误包括 `-32700` JSON 解析失败、`-32600` 请求格式／协议错误、`-32601` 未支持的方法、`-32602` 参数错误。请求不超过 64 KiB，不支持 JSON-RPC 批量数组。权限失败仍可能由 HTTP 认证中间件直接返回普通错误体。

## 3. 可选世界事件 WebSocket

当前 Demo 可以继续使用 HTTP 世界事件／快照。此处记录已存在的可选 WS 协议，不代表需要改动现有前端。

启用并确认 `capabilities.world_event_stream=true` 后，连接 Bootstrap 提供的 `world.stream_url`（路径 `/v1/realtime`），携带普通 HTTP 的认证及三个请求 ID、X-Schema-Version，另加：

```http
X-Stream-Protocol-Version: 1.0.0
Sec-WebSocket-Protocol: yaya.runtime.v1
```

首帧示例，stream_id 使用 Bootstrap 对应的世界流：

```json
{
  "frame_type":"subscribe",
  "protocol_version":"1.0.0",
  "request_id":"req_world_ws_0001",
  "stream_id":"world:world_demo_001",
  "after_sequence":0
}
```

恢复时 frame_type 改成 `resume`，增加先前的 subscription_id，并填写已经连续应用的 after_sequence。其他字段保持相同结构。

服务端首先发送 `subscribed`，包括 request_id、subscription_id、stream_id、accepted_after_sequence、high_watermark_sequence、heartbeat_interval_ms、max_unacked_events；随后发送已提交 WorldEvent。WorldEvent 的结构与 HTTP 世界事件定义一致；它不是语音事件，也不是 AgentInteraction。

前端按 event_id／sequence 去重，只 ACK 已经连续处理的最大序号：

```json
{
  "frame_type":"ack",
  "protocol_version":"1.0.0",
  "subscription_id":"sub_demo_00000001",
  "stream_id":"world:world_demo_001",
  "sequence":1,
  "event_id":"evt_demo_00000001"
}
```

收到 `heartbeat` 后使用它的 subscription_id 和 nonce 回复：

```json
{
  "frame_type":"heartbeat_ack",
  "protocol_version":"1.0.0",
  "subscription_id":"sub_demo_00000001",
  "nonce":"hb_demo_00000001",
  "received_at":"2026-09-09T10:00:00Z"
}
```

不假定心跳严格固定间隔。收到 `error` 时解析 error.code、close_code、retry_after_ms；序列缺口通过 HTTP events／snapshot 恢复。常见关闭码：4400 请求／ACK 无效，4404 世界不存在，4409 游标缺口，4500 服务错误；鉴权和协议错误还可能在握手前直接关闭。

完整公共定义：[runtime-events.asyncapi.json](../../../agent/contracts/asyncapi/runtime-events.asyncapi.json)。不要用这个协议去连接问叮当语音。

## 4. 可选客户端事件上报

`POST /v1/client-events:batch`，完整字段见 [ingestClientEventBatch](HTTP接口参考.md#ingestclienteventbatch)，[请求示例](examples/game-client-event-batch-request.json)。

必填 batch_id、session_id、world_id、first_sequence、last_sequence、events。每批 1–500 个事件，按 sequence 连续排序，边界等于首尾事件序号，event_id 不重复。每条事件含 event_id、sequence、occurred_at、event_type、world_revision、payload，payload 随类型变化。

事件类型：UI_ACTION、CODE_EDITED、BUILD_REQUESTED、HINT_VIEWED、FEEDBACK_SHOWN、ANIMATION_COMPLETED、CLIENT_ERROR、SESSION_HEARTBEAT。

接口记录已经发生的客户端行为；CODE_EDITED 不替代保存草稿，BUILD_REQUESTED 不会替代编译接口，HINT_VIEWED 不会发起教学提问。202 后通过 Command 查询结果。客户端事件序号单独管理，不使用世界序号或聊天序号替代；批次存在缺口时整体失败。

## 5. 没有提供给当前学生前端的操作

下列内容不能仅凭旧 OpenAPI 或内部代码存在就发请求：

- 独立 `/run`、`/chat`、`/bug-agent`、`/teaching-agent`、`/book-agent` HTTP 接口。
- 学生登录／注册、删除会话、草稿历史列表／回滚、完整 LearnerProfile 学生查询接口。
- 飞书 webhook、内容发布、审批决定、报告任务等旧合同中的其他写接口；当前 app 没有挂载它们。
- 数据库表、学习 Worker、模型 relay 和内部 `get_game_context` 工具均不是前端 API。

这些边界用于说明目前可调用的功能，不要求为 Demo 增加上述接口。
