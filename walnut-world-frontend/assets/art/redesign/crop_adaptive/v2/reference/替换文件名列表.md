# 动态素材包 V1 · 替换文件名列表

这是一版独立的 2D 状态动画素材包。只新增素材和本说明；没有修改原来的 Markdown、HTML、静态图片、Godot 项目或后端。

已生成 **98 段动画**：环境背景 6 段；角色状态 28 段；浇水设备 14 段；作物状态 20 段；土地与轮廓高亮 15 段；水流与归档特效 7 段；按钮与输入反馈 8 段。

## 2. 路径与接入方法

- 本说明中的“原文件”相对 **V2 美术资源包根目录**。
- “新文件”相对 **本文件所在的 `动态素材包_V1/`**。从 V2 根目录引用时，在新路径前加 `动态素材包_V1/`。
- 每段有 `.webp` 动图和 `-poster.png` 静态回退图。除背景外，另有 `-atlas.png` 透明图集与 `metadata/<动画名>.json`。不依赖外部网站或生成缓存。
- 游戏接入优先使用透明 PNG 图集，按 JSON 中的 `atlas.frames[].rect` 和 `durationMs` 播放；不要只把原 PNG 改名成 WebP 就假定游戏引擎会播放。图集上限为 4096×4096。
- JSON 已写入逐帧裁切坐标、原图对应关系、画布尺寸、枢轴 `pivot`、首帧内容边界 `contentBounds`、循环与单次播放规则。透明留白不可当成原素材边界强行拉伸。
- 角色画布统一为 448×576，脚底锚点位于画布约 95% 高度；同一角色状态以脚底对齐。动画有新手势的外伸空间，点击区域继续用原逻辑区域。
- 背景统一 1280×720、固定镜头，提供 WebP / MP4 / WebM / OGV 四种格式。保持原背景显示矩形与覆盖方式，建筑与中间交互区没有镜头位移。
- WebP 是可查看的成品；精确逐帧时序以 JSON 为准。编码器可能合并相同帧，但总时长不变。
- 减少动态效果或页面不可见时，停动画并显示对应 poster；无文字的水花／高亮特效可以直接隐藏。
- 按场景和当前状态加载资源，不要同时加载全部图集。运行包只保留实际选用的一种播放格式；PNG 图集和多个视频格式一起存放是交付备选，不是要求全部加载。

完整机器可读映射：[animation-manifest.json](animation-manifest.json)。

## 3. 动作设计与触发规则

| 类别 | 哪些状态动 | 怎么动 | 哪些不动 |
|---|---|---|---|
| 环境 | 当前场景可见且未暂停 | 叶梢错相摇摆、溪水折光沿下游推进、局部暖光低频微变、少量浮尘 | 建筑、主干、桌面、文字区、镜头 |
| 六位角色 | 待机、说话、思考、成功 | 呼吸眨眼；说话时切换新绘口型和手势；思考点头；成功一次轻弹回应 | 脚底锚点、角色身份、服装和道具 |
| 主角 / 小核桃 | 写代码、读取湿度、失败后复查 | 铅笔手腕书写；湿度镜探测；短暂停下、轻微侧摆复查 | 复查时不喷水、不显示假成功 |
| 设备 | 启动、工作、停机、异常 | 局部杠杆/机身运动；读数亮表盘；工作喷水；结束收束 | 待机、异常无水；石底座不抖动 |
| 四种作物 | 重干、轻缺水、达标、过湿、受水 | 对应原形态轻摆；达标舒展、干枯无力、过湿沉重；受水轻压后回弹 | 根部不漂移，不凭动画更改湿度或生长状态 |
| 土地 | 湿润、积水、受水、选中/焦点/错误 | 泥面微光、局部水纹；使用当前土地 Alpha 外轮廓发光 | 干土和石边不呼吸缩放，绝不恢复旧矩形高亮框 |
| 交互 | 悬停、按下、焦点、处理中、成功、错误 | 小幅压下/回弹，稳定焦点脉冲，独立加载转子，错误一次反馈 | 按钮文字、禁用态、输入内容、未解锁项 |

关键约束：只有当前说话者播 talk；台词结束切 idle。本包是泛化口型循环，不是依据实际配音生成的音素级口型同步。角色动作不包括八方向行走或骨骼工程。

浇水必须由合法世界动作触发，不在“加载中”播放。1 份与 2 份动画按约 2 秒／4 秒区分，份数和 250 ml / 500 ml 仍由原教学逻辑控制；播放完不能自行改湿度、判成功或解锁。暂停时冻结进度，恢复时从已保存动作进度继续，不重放一次已完成浇水。

单次成功、错误、印章、归档只播一次；循环只用于环境、待机、说话期间和进行中反馈。未解锁的未来技能保持锁住，不能因有解锁特效资源而自动变成可用。

## 5. 配套文件名规则

例如 `characters/char-player-talk.webp` 同组对应：

- `characters/char-player-talk-atlas.png`：逐帧透明图集。
- `characters/char-player-talk-poster.png`：静态回退。
- `metadata/char-player-talk.json`：裁切、时长、锚点和触发状态。

所有其他动画同样按完整动画名匹配。背景没有巨大的 PNG 图集，以同名 `.mp4` / `.webm` / `.ogv` 播放；后台需逐帧时可从新包的源制作脚本导出，不必重画。

## 6. 不建议转换为循环动画的素材

原 `soil-severe-dry.png`、`soil-light-thirst.png` 的泥土基底、名称牌、数据牌、HUD、代码卷轴面板、数字/数组/箭头等静态解释图标，以及 disabled 输入框/按钮保持原文件。数据与文案不烘焙进动画。解锁树的木架保持静止，解锁时使用独立的四星印章动画；不让整个技能树持续闪动。

水量不足不必新增一个与轻缺水相矛盾的“开心作物动画”；继续显示实际湿度对应的形态和原提示。此包未添加配音、音效或改写教学规则。

## 7. 制作来源与验收

- 经你同意，使用本地透明抠图、连通轮廓拆帧、脚底注册、局部动画变形和编码；原始资源均未覆盖。未采用带背景的失败重画稿作为成品。
- 环境从现有背景制作局部动效，遮罩在 `source/rigs/`；红通道是风区域、绿通道是水面。不是重新生成一张构图不同的背景。
