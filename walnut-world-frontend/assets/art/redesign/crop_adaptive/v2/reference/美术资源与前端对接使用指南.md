## 03 · 全局布局、图层和组件接法

统一设计画布为1672×941，横屏。坐标从画布左上角开始。等比缩放 scale=min(可用宽/1672,可用高/941)，画布居中留边；不能分别拉伸X/Y。桌面验收建议至少1280×720。小屏保持横屏、字号可读或允许外层查看器缩放，不能把所有文字继续挤小；竖屏响应布局尚未设计，不能宣称已经适配手机。

| --- | --- | --- |
| 00 背景 | B01—B06 | 1672×941铺底，cover；场景切换才替换，不在每个输入事件重建。 |

guide-layout.json 的 order 是当前回拼中的实例绘制顺序，不是可直接替代 Godot 所有节点 z_index 的全局常数。移植时保留父子关系与上述语义层级；抽屉覆盖右半农田是有意的遮挡，但正文/按钮之间互相覆盖不是。资源检查器可看到被抽屉盖住的底层资源仍存在。

土地高亮修订（2026-09-05）：fx-selected、fx-focus、fx-error三种独立框全部停用。直接对正在显示的soil-*.png施加基于透明通道的外发光，分别表示金色选中/扫描、浅青色键盘焦点、红色错误；轮廓自动适配土地透视形状和四种干湿状态。金色使用沿alpha四方向1px的浅色近缘＋6px柔光，呼吸峰值柔光9px；焦点和错误使用近缘2px＋柔光7px。保持原图(0,54,229,151)的大小、位置、比例和透明留边，不缩放土地；不能用box-shadow、border或圆角矩形替代。

![三种新反馈：同一土地PNG的金色选中、浅青焦点、红色错误外发光](./qa/guide/soil-feedback.png)

| 替代的旧框 | 新实现 / CSS类 | 显示条件与优先级 |
| --- | --- | --- |
| fx-selected.png（停用） | 当前soil纹理＋soil-selected；暖金外光 | 当前比较/扫描土地；轻呼吸，尺寸保持不变。 |
| fx-focus.png（停用） | 当前soil纹理＋soil-focused / 原生focus-visible；浅青外光 | 键盘Tab焦点；不能把焦点当成已经完成选择。 |
| fx-error.png（停用） | 当前soil纹理＋soil-error；红色外光 | 当前手动判断错误；保留文字解释，错误覆盖选中金光；同时有键盘焦点时保留浅色细近缘。 |

准确接法：[共享外发光样式](./soil-glow.css)；DOM仅给土地img添加soil-sprite和soil-selected。不要给.plot容器、作物、编号牌、湿度文字或点击热区加filter。土地仍先于作物和数据牌绘制，光晕自然位于它们后面。键盘焦点使用同一alpha轮廓的浅青外光；减少动态效果时保持静态光晕。guide-layout.json的对应土地实例增加effect.type=soil-alpha-outline、source=same-image-alpha、separateTexture=false，不新增图片相对路径。

```css
.soil-selected {
  /* 只加在当前土地PNG上；透明轮廓决定形状，非图片外接矩形 */
  filter: drop-shadow(1px 0 0 #fffad5)
          drop-shadow(-1px 0 0 #fffad5)
          drop-shadow(0 1px 0 #fffad5)
          drop-shadow(0 -1px 0 #fffad5)
          drop-shadow(0 0 6px #ffcd38);
}
/* 完整的呼吸/键盘焦点/错误/减少动态效果规则见 ./soil-glow.css */
```

Godot接入：在单块土地TextureRect的材质/其背后的特效层中，取当前土地纹理的alpha生成外扩柔光；只绘制原不透明轮廓之外的光晕，原土地正常绘制。切换干湿纹理时同步使用新纹理作为遮罩，预留边缘扩展范围避免光晕被控件/UV边界裁掉。不要把材质挂到包含植物和文字的整张PlotCard上，也不要新增一张通用高亮框图。三张旧fx框仅作为历史文件保留，manifest均标记deprecated=true；图库不再将它们展示为可接入资源。原型概念稿中的旧框不再是接入依据，以本轮回拼与演示为准。

## 04 · 全局按钮状态规范

| 状态 | 资源包相对路径 | 何时出现/退出 | 交互约束 |
| --- | --- | --- | --- |
| 常态 · normal | [`./components/button-normal.png`](./components/button-normal.png) | 可操作，鼠标未进入；等待用户操作。 | 沿用原handler；不新增用途。 |
| 悬停 · hover | [`./components/button-hover.png`](./components/button-hover.png) | 指针进入可操作按钮；离开恢复常态/焦点。 | 只换皮肤，不提前执行业务。 |
| 按下 · pressed | [`./components/button-pressed.png`](./components/button-pressed.png) | 按下鼠标/触屏；抬起才按原按钮规则触发。 | 不在pointerdown与click各触发一次。 |
| 禁用 · disabled | [`./components/button-disabled.png`](./components/button-disabled.png) | 前置步骤未完成、下一关未开放、当前不可回放。 | 真正disabled，不只是变灰。 |
| 等待 · loading | [`./components/button-loading.png`](./components/button-loading.png) | 已有操作正在等待结果；反馈完成/失败才退出。 | aria-busy/等待语义＋真正禁止重复提交。 |
| 成功 · success | [`./components/button-success.png`](./components/button-success.png) | 教学输入检查正确等短暂确认；240ms后自动进入下一页。 | 不增加一次额外“确认正确”点击。 |
| 键盘焦点 · focus | [`./components/button-focus.png`](./components/button-focus.png) | 键盘Tab选中；焦点离开后恢复，不因鼠标不在按钮上而消失。 | Enter/Space可触发；始终可见焦点标记。 |
| 错误 · error | [`./components/button-error.png`](./components/button-error.png) | 当前操作失败的短反馈；旁边同时出现原因，允许修正重试。 | 不能只靠红色；保留输入和原有错误证据。 |

状态优先级：业务禁用/等待 > 正在按下 > 错误/成功反馈 > 键盘焦点 > 悬停 > 常态。若错误皮肤存在且控件仍有键盘焦点，错误底图与独立焦点外圈应同时可见。尺寸、锚点、按钮标签和可点击范围在换图时不变化。水量按钮常态可用 button-water-green / button-water-blue，但悬停必须有明确亮度变化，按下/禁用仍回全局规范。

本页中的组件试验区展示完整8态；演示中的实际按钮可测试悬停、按下、Tab焦点与禁用。等待/成功/错误图不意味着允许任意页面新增后端阶段或错误原因。

## 07 · 时序、特效与可访问性

| 事件 | 时序与资源 | 退出/可中断规则 |
| --- | --- | --- |
| 入场/切页 | 约200ms淡入；人物 char-*-idle 约2.8s轻呼吸 | 不等待整段演出来决定业务成功。减少动态效果设置关闭呼吸与漂浮。 |
| 打开卷轴 | 正式设计约0.32s右侧滑入；ui-panel+ui-code+原CodeEdit | 用户关闭不清空草稿。演示器采用统一淡入，正式接入保留原抽屉Tween。 |
| 对话 | 正文约34字/秒；ui-dialogue+角色+ui-nameplate | 首次点击补全本句，再点下一句；每句有完整态；不能点击穿透到底下的输入框。 |
| 选中/扫描土地 | 当前soil-*.png的透明轮廓外发光，约1.7s轻呼吸；错误时仍保留解释 | 误点只增强当前目标土地的外光晕，不缩放或闪灭土地，不推进序号；旧fx-selected图停用。 |
| 扫描→浇1份 | 扫描约220ms；prop-nozzle+fx-water-one+fx-splash约600ms | 特效只在当前i；结果标签另占底部位置，不盖住作物。 |
| 扫描→浇2份 | 扫描约220ms；fx-water-two的更强水流约600ms | 2份用份数和500 ml共同说明，不只靠水流粗细区分。 |
| 跳过 | 扫描后约220ms；无水流、无新飞溅；结果“跳过” | 原湿度不改，喷头关闭。 |
| 结果庆祝 | fx-celebrate约2s淡出下落；角色可用success立绘 | 粒子不吃鼠标，不能挡下一步；无动画设置直接保留完成卡。 |
| 候选速度/跳过/重播 | 1x/2x只改变播放节奏；重播同一结果副本 | 不创建第二次运行；本地教学旧工具不因新按钮皮肤获得候选专有操作。 |

这些是可用静态美术驱动的位移、透明度与缩放示意，不是完整逐帧角色动画。若后续要求走路、完整拿壶/举卷轴动作、连续生长帧，需另画同角色帧序列并确认骨骼/切片方案；当前独立立绘不应被当作已交付动作精灵图。音效可接现有项目声音，但此PNG资源包不宣称含新录制BGM/配音。

键盘与读屏：按钮使用真实button，输入使用input/textarea；装饰不进入Tab顺序；对话覆盖时焦点留在继续区域，关闭后回到原操作；错误区使用可读文本与状态提示。点击热区跟随同一缩放矩阵，不按截图显示尺寸再写一套坐标。长错误消息不截断，必要时内部滚动。
