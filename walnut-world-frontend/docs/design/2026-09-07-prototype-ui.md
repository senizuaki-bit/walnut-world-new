# 清泉村原型界面改造

## 问题

学生端已有作物适配浇水器的教学流程，但浅绿背景、平面卡片、大尺寸对话浮层与用户提供的 S01–S10 / E01–E07 原型不一致。

## 结论

正式入口 `scenes/app/app_root.tscn → game_flow.tscn` 所加载的首页和作物关卡已接入农场／工坊背景、木框羊皮纸、橙色主按钮、场景角色与节点树。所有文字、土地数据、代码编辑器、填空输入和按钮仍是 Godot 原生控件。

完整截图索引：[打开 17 个原型状态的实机截图](prototype-review.html)。这些截图使用本地状态夹具，证明界面渲染，不代表真实 Gateway 或 Agent 的业务成功。

## 关键理由

- 首页采用左侧标题木牌、右侧探险者与小核桃的构图；八块农田采用两排四列的预置节点。
- 代码卷轴打开时缩放并移动左侧农田，八块土地全部可见；关闭后恢复。
- 工坊数据配对、分级动作、理解汇总、AI 修改预览及成长档案复用室内背景。
- 对话头像放在底部木框内部，正文可滚动，支持鼠标、触摸、空格和 Enter。继续提示与问题区域分离。
- AI 修改页采用修改前后并排对照，保留显式接受、拒绝和关闭预览，接受后仍只生成草稿。
- 修复成长档案中 `[i]` 被 RichTextLabel 误作斜体标记的问题。

## 做出的决定

1. 优先使用 `.tscn` 预置 Control、Container、TextureRect；脚本负责已有信号与状态驱动的显示布局。
2. 共享资源位于 `resources/ui/`：`prototype_theme.tres`、`parchment_panel.tres`、`parchment_compact.tres`；木框使用九宫格纹理。
3. 用户链接 `https://qingquan-art-resource-guide.mira3277777.chatgpt.site/#prototypes` 在本环境被站点拦截，无法获取高清原图。本轮以用户附上的 2880×2633 原型总览为构图依据，使用仓库既有角色和作物素材。
4. 新增背景由内置 image_gen 生成，属于按参考风格补充的素材，不能称为原型原始美术或逐像素复刻。

## 素材来源与生成提示

- `assets/art/prototype/farm_backdrop.png`：内置 image_gen，参考用户原型总览。提示为 16:9 手绘童话农场，左上树冠、远山蓝天、右侧木屋水车与溪流、前景石路花草，中央 65% 保留空地，无角色、文字、地块、面板或按钮。
- `assets/art/prototype/workshop_backdrop.png`：内置 image_gen，参考 S03–S06。提示为 16:9 温暖木屋工坊，圆窗、木梁、铜管齿轮、书架与阳光木地板，中央保留教学板位置，无角色、文字或 UI。
- 角色、作物与土壤沿用 `assets/art/generated/`。木框与技能连线是项目内可编辑 SVG 界面资源。
