# 清泉村 V2 原型还原

> 2026-09-08：已将V2布局与`fronted-art`的动态资源接入合并，最新来源核对、80项回归与21页截图见[双素材包复核](two-pack-audit.md)。下文保留合并前的实现记录。

本次改造以用户提供的 `作物适配浇水器_美术资源包_V2` 中 `demo.html`、`guide-layout.json` 和 `qa/guide` 为依据，替代此前仅凭拼图制作的界面。学生端仍使用 Godot 4.7.1。

## 资源与布局

- 原始画布为 1672×941，按 `720 / 941` 等比映射到现有 1280×720 逻辑视口；窗口保持宽高比。已检查 1600×900 实机截图。
- 引入 100 张原始 PNG，覆盖六个背景、角色、作物与土地状态、木框、按钮、输入框及技能树组件。`assets/art/redesign/crop_adaptive/v2/source-checksums.json` 记录逐文件 SHA-256，均与用户素材包一致。
- 排除素材包已弃用的 `fx-selected`、`fx-focus`、`fx-error`，土地提示沿当前土壤图片的 alpha 轮廓绘制。
- 保留原名及 `guide-layout.json`、`asset-manifest.json`、`skill-tree-data.json`，方便继续逐页核对。
- V1 的单份水、双份水图集已接入执行演出，帧区域预先声明在 `v1_watering_effects.tres`。未全量启用 V1 的 98 个动画片段。

## 实现约束

- UI、技能树插槽、代码输入和 Patch 三个操作按钮均为预置场景节点。文字与输入为真实控件，未使用整页原型图覆盖交互。
- `v2_surface.gd` 只调整预置 NinePatchRect 的尺寸和素材状态。网页 CSS 的源图切片宽度与显示边框宽度是两个参数，不能直接套用 Godot 默认 StyleBoxTexture 拉伸，否则木框过粗、短铭牌变形。
- S07 卷轴覆盖右侧农田，保持八块土地的原始位置与尺寸。代码区保留同一个 CodeEdit、草稿和撤销栈，长行支持横向滚动。
- 工坊保留两步输入校验、错误值、字段错误状态及继续修改；不会把练习答案自动填入完整代码。
- Patch 保留关闭、拒绝、接受的不同含义；接受只生成草稿，仍由学生再次运行。
- 候选 hydration 保持现有 0–10000 量纲，状态图按 evaluator 结果变化，候选表现不改写世界数值。
- 正式 Agent、Run、Receipt、Snapshot、内容与草稿接口延续原实现。世界标识信息移入阶段栏提示，避免挤占原型的流程栏。

## 验证与预览

- 完整离线回归：79/79 通过，包含角色展示、教学流程、候选兼容、接口链路与场景测试。
- `v2_prototype_contract_test.gd` 独立读取原始布局，检查首页、工坊、技能树、反例、归档与卷轴边界，以及土地轮廓、输入错误和候选量纲。
- 最终归档排版调整后，教学流程测试与原型契约测试再次通过。
- `art-v2-review.html` 提供 21 个实机画面；六个核心页面附原始回拼图并排对照。截图为本地教学与展示测试状态，不是线上运行回执。
- `verification/art-v2-tests.json` 为完整测试结果；`art-v2-captures.json` 记录页面映射。

尚未进行线上真实网关端到端验收，也未逐项人工走查素材包的全部 74 个演示子状态。系统字体在不同操作系统上可能有字形差异；后续调整继续以原始组件和布局数据为准。
