# UI 注意力与补间动画改造验收记录

日期：2026-08-10

> 历史验收：本文记录第一轮注意力改造，不代表当前循环浇水魔法版本。旧横向设备、调试按钮和变量统计已在后续版本删除；当前验收见 `loop-magic-completion-audit.md`。

## 本轮范围

- 收敛主世界与横向自动浇水 Demo 的常驻 HUD；
- 取消任务卡频繁展开/收起；
- 将普通教学对话压缩为自动消退的单行气泡；
- 编程阶段固定显示代码区与运行结果区，不再提供开合操作；
- 代码工作区显示时降低世界 HUD 权重；
- 将保存反馈聚合到代码抽屉标题栏；
- 使用目标环、顺序路径、`i` 浮标和变量地图替代主要文字引导；
- 默认隐藏变量地图与统计，通过“查看调试”按需显示；
- 将儿童可见输出从 `WATER` 改为“浇 X 号土地中…… / 浇灌完成！”；
- 将边界错误反馈从中央 Bug 弹窗迁移到变量地图；
- 补充目标推进、气泡、固定编程台、变量运行、按钮和完成状态补间；
- 自动阶段由浇水设备与移动喷头标记逐块执行，小核桃保持原位并降权；
- 完成时先展示幼苗抬升和“全部发芽啦”，随后再出现精简结算。

## 视觉自检结论

- 常态不再出现右上保存胶囊；Demo 只保留提示入口，代码开合入口隐藏；
- 任务状态卡固定紧凑，不再承担长目标文本和开合交互；
- Demo 普通对话为单行短气泡，科技解锁出现时与其互斥；
- 代码阶段的任务卡和阶段条自动降权，固定编程台持续显示代码与运行结果；
- 变量地图与四项统计默认隐藏，只有主动点击“查看调试”后才占用版面；
- 连续边界错误不会弹出中央 Bug 卡，缺失土地 `4` 在变量地图中直接标红；
- 自动阶段不再移动小核桃，而是以设备高亮、移动喷头标记和逐块土地动画表达运行；
- 最后一次浇水后先显示发芽结果，再显示完成标题、获得能力和下一步锁定三项；
