# 《横向自动浇水器》Demo 关卡方案

> 核心知识：单个 `for` 循环变量 `i` 遍历；体验时长：约 8—10 分钟。
> 世界能力：让小核桃自动浇完一排土地

## 1. 关卡目标

芽芽刚种下一排幼苗，玩家先逐块指挥小核桃浇水，随后解锁“横向自动浇水器”，使用一个 `for` 循环让小核桃自动浇完 0—4 号土地。

唯一新增知识：

```cpp
for (int i = 0; i < 5; i++) {
    cout << "WATER " << i << '\n';
}
```

玩家需要理解 `i` 从 0 开始，依次变成 0、1、2、3、4，并代表当前土地编号；本关不涉及 `cin`、数组、`if`、双重循环、二维数组、函数、类和排序。

## 2. 角色职责

- 芽芽：介绍幼苗和浇水目标，不评价代码。
- 小核桃：执行玩家的手动操作与真实学生 Skill；没有真实运行结果时不能声称任务完成。
- 叮当师傅：解释循环变量，并根据真实遗漏、重复或越界结果提供提示。
- Bug：只在同类循环边界错误连续出现两次时出现，并展示真实变量记录。
- 书书：任务客观完成后总结代码变化并保存 Skill。

## 3. 核心流程

1. 玩家依次点击 0—4 号土地，形成五条 `WATER` 指令。
2. 第二排幼苗出现，芽芽和叮当引导玩家发现五条指令只有土地编号不同。
3. 科技树从“手动水壶”点亮“循环变量控制”，再解锁“横向自动浇水器”。
4. 玩家补全 `for (int i = __; i < __; i++)` 与输出中的 `__`。
5. 小核桃按 `i = 0` 到 `i = 4` 逐格真实执行，界面同步显示已浇、重复、越界与遗漏统计。
6. 仅模拟器通过后，幼苗抬叶、横向水管点亮蓝色光纹，书书保存“横向自动浇水 Skill v1”。

## 4. 主要错误反馈

- 从 1 开始：遗漏 0 号土地。
- `i < 4`：遗漏 4 号土地。
- 输出没有使用 `i`：重复浇 0 号土地，遗漏 1—4 号土地。
- 连续两次遗漏最后一块土地：Bug 展示两次运行中的 `i` 都为 0、1、2、3，始终没有 4。

## 5. Demo 边界

当前 Demo 到“横向自动浇水器”解锁并成功运行后结束；后续一维数组、`for + if`、双重循环、二维数组和排序只在科技树中显示为锁定，不进入教学。
